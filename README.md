# 任务看板系统 (Task Panel)

## 项目简介
基于 Vue3 + Pinia + Element Plus 开发的轻量级任务看板系统，采用 Trello 风格设计，支持任务拖拽、进度统计、数据导出等核心功能。

## 功能特性

### 📋 核心功能
- **任务列管理**：待处理、进行中、已完成三列任务流
- **拖拽交互**：任务卡片自由拖拽，流畅动画效果
- **任务操作**：新增、编辑、删除任务
- **进度统计**：实时显示总任务数、已完成数、完成率
- **数据持久化**：localStorage 自动保存，刷新不丢失
- **数据导出**：支持 JSON/CSV 两种格式
- **截止日期提醒**：过期/临近任务高亮显示

### 🎨 扩展功能
- **任务优先级**：高/中/低三级优先级，彩色标签区分
- **响应式布局**：适配桌面、平板、手机等设备
- **现代化 UI**：Element Plus 组件库，渐变背景主题

## 使用说明

### 1. 添加任务
- 点击任务列顶部的「新增」按钮
- 填写任务标题、描述、优先级、截止日期
- 点击「创建」完成添加

### 2. 编辑任务
- 点击任务卡片进入编辑模式
- 修改任务信息后点击「保存」

### 3. 删除任务
- 点击任务卡片右上角的删除按钮
- 确认后删除任务

### 4. 拖拽任务
- 按住任务卡片拖动到目标列
- 松开鼠标完成移动

### 5. 导出数据
- 点击页面顶部的「导出数据」按钮
- 选择导出格式（JSON/CSV）
- 选择要导出的任务列
- 点击「导出」下载文件
